# Emoji Racing

A simple Python terminal game where multiple players compete by earning
random points in each round.

Features
--------
- Multiple players
- Custom player names
- Custom emoji symbols
- Colored player displays
- Random scoring
- Live leaderboard
- Configurable rounds and scoring

Requirements
------------
- Python 3
- colorama

Installation
------------
Make sure to run 'pip install colorama' in your CMD before running the code

Running
-------
python main.py
